# My Pong — 10 Levels

Now with improved playability:
- Responsive/high-DPI canvas scaling
- Start button (required to enable audio on modern browsers)
- Touch controls for mobile
- Single AudioContext created on first user interaction

How to run:
1. Open `index.html` in a modern browser (or host with GitHub Pages).
2. Click Start (or press Space) to begin.
3. Use W/S or Up/Down to control the left paddle. On mobile, use the touch buttons.
