# My Pong — 10 Levels

A single-file HTML/CSS/JS Pong game with 10 increasing difficulty levels, red and blue color scheme, sound effects, and simple AI.

Features
- Red player paddle (left) and blue AI paddle (right)
- 10 distinct levels — each level changes ball speed, paddle sizes, AI reaction and obstacles
- Keyboard controls: W / S and Up / Down to move; Space to start/restart; P to pause
- Sound effects (hit / score)
- Responsive canvas scaling to the game viewport size

How the levels work
- Level 1: easy speed, tall paddles, slow AI
- Level 2–9: progressive increases in ball speed, reduced player paddle height, stronger AI reaction
- Level 10: maximum speed, smallest paddle, sometimes multiple-bounce behavior for added challenge

How to run
1. Open `index.html` in a modern browser.
2. Press Space to start.
3. Use W/S or Up/Down to control the left paddle.
